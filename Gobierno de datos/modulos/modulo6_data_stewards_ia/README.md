# 👤 Módulo 6: Asistencia Operativa a Data Stewards & Preparación para IA / RAG

## 📌 Propósito y Capacidades
Este módulo asiste a los responsables funcionales de datos (Data Stewards / Data Owners) y garantiza que los datasets destinados a alimentar modelos de Inteligencia Artificial Generativa y Retrieval-Augmented Generation (RAG) estén 100% gobernados y certificados.

### Funcionalidades:
1. **Mapeo de Stewards por Dominio:** Asigna responsables a dominios como Clientes, Finanzas, Operaciones, Ventas e IA.
2. **Certificación para IA / RAG:** Valida que solo datasets con calidad Dataplex > 90% y con enmascaramiento dinámico (DDM) activo en campos PII puedan ser consumidos por agentes inteligentes.
