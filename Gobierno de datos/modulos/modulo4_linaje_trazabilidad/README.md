# 🔗 Módulo 4: Linaje de Datos y Trazabilidad End-to-End

## 📌 Propósito y Capacidades
Este módulo reconstruye el grafo completo de origen y destino de cada activo de datos a través de entornos heterogéneos (ETLs, CDC, Data Lakes, Datamarts y Modelos de IA).

### Capacidades Principales:
1. **Grafo Visual Interactivo:** Representación gráfica en SVG de fuentes upstream, tablas analíticas y consumidores downstream.
2. **Análisis de Impacto:** Evalúa automáticamente qué dashboards (Looker/PowerBI), pipelines analíticos o agentes RAG se verán afectados ante la alteración o eliminación de columnas.
